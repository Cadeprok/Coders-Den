# Coders Den

Welcome to Coders Den, a full stack e-commerce website for selling coding classes. This project is built using HTML, CSS, Python, Flask, and JavaScript.

## Features

- **User-friendly interface**
- **Responsive design** for various devices
- **Secure user authentication and authorization**
- **Browse and search** for coding classes
- **Add classes to cart** and checkout
- **Admin panel** for managing classes and users

## Technologies Used

- **HTML**: For structuring the website content
- **CSS**: For styling the website
- **Python**: For backend logic and server-side programming
- **Flask**: As the web framework for Python
- **JavaScript**: For client-side scripting and interactivity

## Running the Application

### 1. Install Dependencies

Ensure you have the following Python packages installed. You can install them using pip:

```bash
pip install Flask
pip install Flask-SQLAlchemy
pip install SQLAlchemy
pip install Flask-Login
pip install Flask-WTF
pip install WTForms
pip install Flask-Bcrypt
pip install Flask-CORS
```

### 2. Run backend

```bash
python3 app.py
```

### 3. Open localhost 

Open localhost, once you run the app you will be able to see where the app is running on, click the top one.
